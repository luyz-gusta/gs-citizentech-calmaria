Rode uma varredura para calcular o indicador.

Risco de um item = peso do dado x peso da exposição (3 público, 2 log e arquivo, 1 banco) x (1 se exposto, 0,2 se barrado). Risco Cidadão = 100 x soma dos riscos / soma se nada estivesse barrado. Faixas: 0 a 20 baixo, 21 a 50 médio, 51 a 100 alto.
